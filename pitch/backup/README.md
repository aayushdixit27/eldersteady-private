# Offline backup runbook

1. Double-click `index.html`; it needs no network, server, board, or package.
2. Keep the “simulated fixed-fixture replay” label visible.
3. Click the replay button and deliver `../demo-script.md`.
4. At the ledger beat, pause on 333,540 and say the exact bold sentence.
5. If the real board fails, do not troubleshoot on stage; finish from this file.

`screen-recording.mp4` is a silent local capture of the same full backup sequence. `01-title.png`, `02-incident.png`, and `03-ledger.png` are fallback stills.

## Limits

The backup demonstrates the pitch and exact fixture arithmetic only. It is not a substitute for board-local execution, model inference, aggregation output, notifications, or eval evidence.
